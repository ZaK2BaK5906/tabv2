# MDT Premium - Design System (V0)

## Vision
UI premium en dark mode avec glassmorphism léger, animations fluides et ergonomie tablette.

## Couleurs principales
- Base 950: #090c12
- Base 900: #0f141e
- Surface 900: rgba(18, 24, 36, 0.9)
- Surface 800: rgba(21, 29, 42, 0.75)
- Accent 500: #55e2ff
- Brand 500: #8a7bff
- Success: #2fd083
- Warning: #ffb545
- Danger: #ff5d73

## Typographies
- Display: Space Grotesk (titres, métriques)
- Body: Inter (texte UI)

## Composants réutilisables
- Button (primary, secondary, ghost)
- Modal (preview facture, confirmation paiement)
- Table (pagination, filtres, badges)
- Toast (feedback actions)
- Badge (statuts)
- Tabs (filtres)
- Drawer (actions rapides)
- Sidebar + Topbar (shell)
- Card (glass-panel)

## Layout / Grilles
- Sidebar 96px, topbar fixe
- Grille 12 colonnes, espacements 24/32px
- Cartes arrondies 20-28px, ombres soft

## États & Animations
- Hover: légère élévation + glow
- Focus: border accent + shadow
- Transition 200-250ms ease-out

## Navigation / Pages
- Dashboard
- Factures
- Employés
- Commissions
- Partenariats
- Taxes / DOJ
- Concessionnaire

## Notes
Le design est pensé pour ajout de modules (Police MDT, EMS MDT) via navigation modulaire.
